> 职责：定义“用什么证据证明 DataScope 改造完成”，以及生产发布/回滚门禁。  
> 本文件不重复 `04` 的实现任务，不自行发明 `03` 尚未批准的性能或监控数字。

## 1. 测试身份与数据集

至少准备：
- ADMIN；
- 同一工厂两个不同单区域账号；
- 同一工厂多区域账号；
- 第二工厂账号（只有在第二工厂字典和测试数据已确认后使用，不默认假设“三山”一定存在）；

- 若 `03` 批准 SUB_ADMIN 委派，增加对应账号；

- AGV、SAP、IMS、PPC 测试身份；自动打印 Agent 已弃用，不列入本阶段验收。

测试数据必须包含：同工厂同区域、同工厂跨区域、跨工厂、未归属 NULL、多候选、无候选、批量混入越权项等场景。

## 2. 基础授权证据

必须证明：
- 登录返回并使用正确可信范围；
- 普通账号缺 factory 或有效区域时 fail closed；
- 修改 Role/factory/areas/enabled 后旧 Session/Ticket 失效；
- 旧 Session 缺新字段时强制重新登录；
- Redis 多实例 Session 失效一致；
- ThreadLocal 在正常/异常请求后都清理；
- 账号委派（如启用）不能分配超出操作者权限的范围；
- 并发修改范围不产生部分成功。

## 3. DataScope 通用矩阵

对每个 `FACTORY_AREA / FACTORY_ONLY / GLOBAL` 对象至少验证：

| 维度 | 证据要求 |
|---|---|
| 列表 | 只返回授权数据，total/分页/排序/搜索/自动补全同口径 |
| 详情/编号 | id、taskNo、labelCode、boxCode、warehouseCode 等不能横向越权 |
| 写操作 | 修改前校验旧实体；客户端范围参数不能扩大授权 |
| 批量 | 混入一个越权项即整批拒绝并回滚 |
| NULL | 新数据缺必要范围拒绝；历史未归属普通账号不可见 |
| 导入 | 文件伪造范围无效 |
| 导出 | 与对应列表授权口径一致 |
| 缓存/异步 | 命中、重放、后台执行不串范围 |
| 日志/错误 | 不返回其他范围明细，不泄露凭据 |

HTTP 状态码按 `03` 最终批准口径执行。

## 4. 业务链专项

### Task / Mapping / PrintJob

- Task 查询、统计、待打印和全部状态动作不跨范围；创建后归属不漂移。
- Mapping 查询、导入、导出、覆盖、删除按范围；同名 area 跨工厂不互相影响；`scope=ALL` 只在批准入口可用。
- PrintJob 列表、创建、补打、取消按最终范围；已弃用的 Agent 领取/回调不属于本阶段验收。

### 扫码

覆盖 preview、empty、receive、exception、幂等/重复提交、断网重试、结果回传，并验证：唯一候选正确写入范围；多候选/无候选/空范围拒绝；employeeNo/Header/请求体不能改写 Task 归属。

### Inventory / Label / Box / AGV / 计划链

按 `03` 最终决策验证其快照、生命周期、唯一键、历史追溯、AGV 回调、WeeklyPlan 激活/冲突、SimpleBOM 活动批次和 ProductionPlan→Demand→Purchase 计算链。

## 5. 旁路专项

必须证明：
- Dashboard/BigScreen/统计/最新记录不显示其他范围数据；
- 普通请求不再依赖全表 findAll/count + 内存过滤实现授权；
- 日志、Recovery、DataQuality、Maintenance 不向普通账号返回全局明细；
- 普通管理员清空只影响自身范围；全局清空有独立 ADMIN 入口、二次确认和审计；
- @Async、定时、Outbox、缓存、自动补全、临时文件、错误报告、下载接口无旁路。

## 6. WebSocket / Redis

至少验证：
- Ticket 使用当前有效范围和 Session 版本；
- CONNECT 使用当前 Session；
- 手工 SUBSCRIBE 未授权 destination 被拒绝；
- 普通账号收不到其他 area/factory 事件；
- FACTORY_ONLY/GLOBAL 事件符合批准规则；
- 公共 topic 不泄露完整业务实体；
- 用户队列/定向推送正确；
- Redis 多实例 relay 不串范围；
- 用户禁用/范围变化后旧连接失效；断线重连使用最新范围。
