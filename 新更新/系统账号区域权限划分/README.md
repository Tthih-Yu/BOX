## 🎯 改造目标

实现工厂与配送区域两级数据隔离：

```
普通账号权限 = Role（功能权限）+ DataScope（数据范围）
数据访问规则 = data.factory == user.factory 
              AND data.deliveryArea IN user.deliveryAreas
```

- 一个账号绑定 **1个工厂** + **1个或多个配送区域**
- `ADMIN` 可访问全部工厂和区域
- 后端强制隔离，前端筛选不作为权限边界

## 🚀 实施流程

### 阶段0：准备工作
- 重新核验代码和数据库现状
- 完成业务归属决策（03文档）
- 创建并验证生产备份

### 阶段1-2：基础设施（1-2天）
- 数据库：用户工厂字段 + 多区域关联表
- 认证链：LoginResult → SessionUser → RequestContext
- 创建统一DataScopeService

### 阶段3-8：业务封堵（3-4天）
- Task、Mapping、PrintJob
- Inventory、Box、Label、AGV
- 计划、BOM、需求、采购
- Dashboard、日志、导出、维护

### 阶段9：WebSocket隔离（1天）
- SUBSCRIBE拦截器
- 事件范围元数据
- 用户队列/定向推送

### 阶段10-12：前端与上线（2-3天）
- 前端范围维护和展示
- 历史数据回填
- 测试、验收、灰度发布
