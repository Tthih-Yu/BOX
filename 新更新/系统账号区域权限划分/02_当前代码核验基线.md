## 1. 总体结论

当前系统已有 7 个 Role、部分业务范围字段、前端工厂/区域筛选、部分扫码归属传递和基础 factory 索引，但尚未形成账号级 DataScope 安全边界。

准确风险表述：

> 在角色权限和业务状态允许的情况下，普通账号仍可能读取或操作其他工厂、其他配送区域的数据。

## 3. 账号、认证、Session、上下文

已核验缺口：
- `UserEntity` 无 `factory`；
- 无用户—配送区域关联表/实体/Repository；
- 用户 DTO、`LoginResult`、`SessionUser` 无范围字段；
- `Users.vue` 不能分配工厂和多个区域；
- WebSocket Ticket 复用缺少范围的 SessionUser；
- `AuthTokenFilter` 只绑定用户和 Role；
- `RequestContext` 只有用户和 Role；
- 无统一 `DataScopeService` / `canAccess()` / `requireAccess()`。

## 4. Task

- Repository 列表、日期、状态、统计、待打印和 taskNo 查询未统一加入 factory/area 条件。
- `TaskService.list()` 存在全局 Top1000 查询。
- taskNo 加锁后的取消、接单、拣料、配送、收货、异常、重试等动作主要校验 Role 和状态，未统一校验实体 DataScope。
- 扫码创建 Task 能从 Mapping 传递 factory，但归属解析存在默认值和多候选问题。

## 5. Mapping

- `deleteByDeliveryArea` 只按区域删除，未同时限定工厂。
- `scope=ALL`、区域删除、IDs 删除、全量导出、导入覆盖/upsert 没有账号 DataScope。
- 普通账号保存时后端未强制使用当前账号可信范围。
- 部分逻辑把缺失配送区域默认成 `1`。
- 全局 upsert 未统一将工厂和区域纳入权限及业务唯一性判断。

## 6. PrintJob

- `PrintJobEntity` 已有 `factory`，没有 `deliveryArea` 快照。
- 列表、编号、状态、待领取查询无统一范围条件；无筛选时存在全局分页查询。
- 从 Task 创建时可继承工厂；人工 taskNo 入口当前缺少统一 Task 范围校验。
- Print Agent 使用统一外部 API Key + `SYSTEM` 身份，未绑定独立 Agent 和工厂。

## 9. Dashboard、统计、日志和维护旁路

已确认存在以下全局查询形态：
- `DashboardService.dashboard()` 对 Inventory `findAll()` 后在内存统计；
- Material、Box、Label 存在全表 count；
- Task 存在全量读取再 stream 过滤；
- ScanLog 最新记录缺范围条件；
- 物料用量统计存在读取范围内外 Task/Mapping 后再处理的风险；
- 日志接口/导出存在 Task、Print、Interface、Scan 全局旁路；
- Recovery、DataQuality 等维护服务遍历全局 Inventory、Box、Label、Task。

Dashboard 是默认首页，因此这些查询会直接暴露为可见风险面。

## 10. 外部系统认证

当前 `AuthTokenFilter` 对外部系统使用统一 `EXTERNAL_API_KEY`：

```text
X-Api-Key == configuredApiKey
        ↓
userId = 0
username = EXTERNAL_SYSTEM
role = SYSTEM
```

因此 Print Agent、AGV、SAP、IMS、PPC 无法天然区分身份、绑定工厂或限制跨工厂访问。

## 11. WebSocket / Redis

已核验：
- `WebSocketConfig` 开放公共 `/topic` Broker；
- `RealtimePushService` 仅传递 `topic + body`，事件无范围元数据；
- 前端订阅公共 `/topic/{topic}`；
- 无 STOMP `SUBSCRIBE` 范围拦截器；
- 无可信 Principal 范围；
- 无用户队列隔离；
- Redis relay 未按连接权限过滤。

因此只改 HTTP 仍会保留实时数据旁路。

## 12. 导入服务

- `SimpleBomService` 使用 CSV 流式导入，约 500 万行级；当前范围模型未完成。
- `WeeklyPlanService` 已有 factory 字段，但导入/激活尚未形成账号范围约束。
- `ImportService` 中 Mapping 等基础数据导入尚未强制账号可信范围。
